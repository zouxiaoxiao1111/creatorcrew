## 1. 一句话结论

中文 AI 自媒体圈现在的主线是：**抢先拿到新 Agent 功能（Grok Bot / Muse / Codex / Claude Skills），做成"保姆级教程 + 可复制提示词"的长文或清单，换来收藏、涨粉，再导流到付费群、商单和咨询**。最大的痛点集中在四件事：模型封号和降智、额度不够用、信息多到追不上、选题和审稿还得靠人工。对他们最有吸引力的工具，要能**帮他们更快产出内容、省额度，并且能直接拿来当选题去晒**。

## 4. 最火的内容形式

1. **X 长文（Article）＋「保姆级 / 大全 / 指南」标题＋附提示词**：这是互动最高的形式。Kin 的微信接入教程 107.7 万浏览，Miles 的出海指南 35.5 万，xaiwind 的 Skill 大全 15.4 万。特点是**收藏数经常高于点赞数**（6,877 收藏对 3,540 赞），说明读者是当工具书收藏的。
2. **数字清单体**：「20 个 Skill」「10 个 Skill 跑完小红书」「5 个 GitHub 仓库」「67 个 Claude Skills」（@0xluffy_eth 几乎每天都发这种）。
3. **引用转发＋情绪化开头**：「卧槽！」「damn」「全体起立！」「绝了！」，抢在官方发布后几小时内用中文解读（Kin、AYi、NFT_Chen、miles_mazy 都这么写）。
4. **实测成片 / 截图 / 演示视频**：「一次性做出来的成片」「只用了免费计划的2%的额度」，用真实产出说服人（@SUOHA_AI 32.7 万浏览）。
5. **晒收益和里程碑**：「开通推特创作者的收益，半个月已经有 300 多刀」「3W粉啦」「每天发发 X，半个月万把块」。这类帖子信任度高，也负责把人导向付费群。
6. **博主榜单 / 精选汇总**：「值得关注的 AI 博主」@HytidelLegend（135 / 183）https://x.com/HytidelLegend/status/2107311258072686917 、「最近12小时的高质量 Grok Bot 推文」@MaiYangAI https://x.com/MaiYangAI/status/2106174948624728273 、「被收藏最多的 10 篇」。
7. **人设化 Bot**：Kin 的 Bot 用宫廷腔回话（「皇上，奴才读完了…」），21 个 Bot 分成"管事的 / 做产品的 / 做内容的 / 管生活的"，带出了 375 收藏、292 赞 https://x.com/KinGao476942/status/2107345071091941833 。
8. 英文圈常见的是 **thread「N examples」＋结尾 CTA「Follow me & Bookmark」**（@minchoi 的固定模板）。

## 6. 对我们工具的启示

### 6.1 最能打动他们的 Bot 模板（按痛点排序）
1. **选题雷达 Bot**：每天定时扫 X 上的关键词和对标账号，抓高收藏帖（直接参考"收藏数"），整理成选题清单，同时把散落在书签里的灵感汇总起来。对应痛点 C 和 D，也是 minchoi 说的「cheapest X research analyst」。
2. **长内容拆解 Bot**：播客或长视频转逐字稿，再提炼十大金句，产出一条可以直接发的推文。Kin 用这个拿到了 13.9 万浏览，是现成的案例。
3. **长文写作 Bot（去 AI 味）**：一手素材进去，出 X 长文初稿、标题和封面提示词，人只花 10 分钟审稿（AYi 的写作 Skill 正是这个思路）。对应痛点 E。
4. **爆款对标 Bot**：把一条爆帖或爆款视频拆成结构、钩子和评论区情绪，套到自己的选题上。
5. **视频流水线 Bot**：脚本、配音、字幕、成片，或者口播的粗剪。
6. **多平台分发 Bot**：一篇长文改写成小红书笔记、公众号文章和 X 短帖。这个圈子普遍同时做 X、小红书和公众号。
7. **涨粉复盘 Bot**：每周统计自己帖子的赞、收藏、浏览和涨粉，找出哪种形式最有效。
8. **额度管家 Bot**：监控用量，提示哪些任务该换便宜的模型、该清理上下文。对应痛点 B（「额度续航指南」能有 322 收藏，说明需求很强）。
9. **商单和私信管家 Bot**：用自带邮箱和 X 私信整理商单询价、报价、排期，再提醒跟进。
10. **社群运营 Bot**：把付费群里的常见问题整理成知识库并自动答疑。他们几乎人人都有 199 元的群。

### 6.2 怎么宣传
- **主推形式就用他们自己的爆款格式**：一篇 X 长文《XX 个 Bot 模板｜一个人顶一个自媒体团队（附可复制提示词，直接发给你的 Bot）》。清单体＋保姆级＋可复制，正好命中"收藏型"内容。
- **一键导入模板、可视化团队面板**：Kin 的 21 Bot 图文和蓝哥的 Template Hub 说明，大家要的是"抄作业"，从零写提示词他们不愿意。可以给模板加人设（总管、写手、剪辑师），本身就有传播性。
- **用真实产出说话**：晒"Bot 早上自动整理好的选题清单截图""4 小时播客 10 分钟出金句"。避免空喊"Agent 时代"，这个圈子已经对 AI 展示和炒概念审美疲劳（痛点 F）。
- **找种子 KOL 共创**：优先找 Grok Bot 重度用户和模板作者（@KinGao476942、@0xlangeai、@MaiYangAI、@AYi_AInotes），以及清单型大号（@0xluffy_eth）。给他们提前体验，借他们"抢首发"的需求。
- **卖点要直接对上痛点**：「省额度」「稳定」「一个人顶一个团队」「涨粉复盘」。"不封号""国内直连"这类说法涉及合规风险，**不建议**作为宣传点。

## 数据局限
- search_posts_all 不支持 min_faves 过滤，按 relevancy 排序会混进大量低互动帖子。所以高互动样本主要来自头部账号的时间线和它们引用的推文，可能偏向少数几个头部账号的圈子。
- 英文部分数据少，而且噪音大（"AI agents for creators"一类查询大量返回加密货币推广帖）。英文结论只基于 @minchoi、@thedankoe 和若干 Grok Bot 用户的推文，代表性有限。
- 只抓了公开推文文本和互动快照，没有看评论区，也没有统计长文正文。粉丝数来自查询当时的资料。
- 没有调用趋势（trends）接口，"热度"是根据互动数据判断的，不是平台热搜。
